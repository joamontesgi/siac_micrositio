\chapter{Arquitectura del sistema}

\section{Propósito}
El micrositio SIAC es una aplicación web institucional del \emph{Sistema Interno de Aseguramiento de la Calidad} de la Universidad Nacional de Colombia. Publica contenidos del simulacro del 6 de octubre, la matriz de indicadores (Excel), documentos clasificados por componentes funcionales y ciclo ACTÚA, y un módulo de administración restringido.

\section{Vista general}
La solución sigue un patrón MVC en Laravel~9, con contenido editorial en JSON estático y persistencia relacional para documentos y usuarios administradores.

\section{Componentes de aplicación}
\begin{itemize}
  \item \textbf{SiacContentRepository}: menú, páginas y contacto desde \texttt{storage/app/data/site\_content.json}.
  \item \textbf{SiacIndicatorRepository}: matriz, filtros y resumen desde \texttt{indicators.json}.
  \item \textbf{Document} (Eloquent): metadatos, etiquetas ACTÚA/componente, \texttt{downloadHref()}, filtros.
  \item \textbf{Vistas Blade}: \texttt{resources/views/siac/*}, layout UNAL, estilos \texttt{public/css/siac.css}.
\end{itemize}

\section{Seguridad}
\begin{itemize}
  \item Área administrativa protegida con middleware \texttt{auth}.
  \item Limitación de intentos de login (10 por minuto).
  \item Descargas servidas por controlador (evita conflicto con carpeta física \texttt{public/documentos}).
  \item Credenciales en \texttt{.env} (\texttt{SIAC\_ADMIN\_EMAIL}, \texttt{SIAC\_ADMIN\_PASSWORD}).
\end{itemize}
